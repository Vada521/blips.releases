# Blip for macOS — releases

Signed builds and the update feed for Blip. Source is private.

Install (no Gatekeeper prompt):

```
curl -fsSL https://github.com/Vada521/blips.releases/releases/latest/download/install.sh | sh
```

Or download the DMG from the latest release (first launch: System Settings → Privacy & Security → Open Anyway).
